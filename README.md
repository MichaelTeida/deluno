# Deluno

Deluno is a modular Software as a Service (SaaS) platform designed with a distinctive "Liquid Glass" aesthetic. It functions as a unified workspace that hosts independent productivity applications, starting with a powerful note-taking tool, all built on a scalable and architectural contract.

## Features

### 🟢 Modular Platform Architecture
A scalable shell featuring an App Picker, a left-side navigation rail, and dynamic layout zones. It utilizes React Portals to inject app-specific sidebars into the main layout seamlessly.

### 🟢 Noter Application
A fully integrated note-taking application ("Noter") featuring rich text editing, hierarchical organization, and a dedicated workspace within the platform.

### 🟢 Liquid Glass Design System
A modern, cohesive user interface utilizing glassmorphism effects (`.glass`), distinct design tokens, and fluid animations powered by Framer Motion.

### 🟢 Rich Text Editor
Advanced text editing capabilities powered by Tiptap, supporting task lists, highlighting, links, and bubble menus.

### 🟢 Authentication
Secure and seamless user management (Sign In / Sign Up) powered by Clerk.

### 🟢 Theme Engine
Native support for Light and Dark modes using Tailwind CSS v4 variables and a custom theme provider.

### 🟢 Drag & Drop Interaction
Smooth drag-and-drop mechanics implemented with DnD Kit for organizing content and notes.

### 🔴 More apps
Future expansions of the platform ecosystem will include new applications.
